# kampfire.digital

Source for the [Kampfire Digital](https://kampfire.digital) website — AI workflow automation for Australian construction-adjacent businesses (energy assessors, builders, building designers).

Static site (HTML/CSS/JS), hosted on GitHub Pages with the custom domain `kampfire.digital`.

## Structure

- `index.html`, `about/`, `services/`, `case-studies/`, `contact/` — site pages
- `css/site.css`, `js/site.js` — single shared stylesheet and script
- `nrg-welcome/` — unlisted client onboarding page
- `sitemap.xml`, `robots.txt`, `404.html`, `CNAME` — plumbing

Deploys automatically on push to `main`.
